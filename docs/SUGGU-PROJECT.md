# Suggu project overview

> This overview was reset on 2026-08-08. The former Clean Architecture-specific design is retired.

Suggu is a globally installable productivity CLI for filesystem work and ordinary .NET solutions. It provides global folder/file creation and directory inspection, plus context-aware .NET commands for code templates, projects, references, builds, and endpoint-flow inspection.

The active specification is [Requirements.md](Requirements.md). Current implementation details are in [Architecture.md](Architecture.md), status is in [Phases.md](Phases.md), and session handoff notes are in [Session-Memory.md](Session-Memory.md).

Historical `SUGGU-CLI-PLAN.pdf` and `tree.json` files are retained only as research artifacts. They do not define current behavior.
