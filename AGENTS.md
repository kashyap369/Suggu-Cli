# Project continuity

Before changing this repository, read `docs/Architecture.md`, `docs/Requirements.md`,
`docs/Phases.md`, and `docs/Session-Memory.md` alongside the relevant source code.

When a change affects implemented behavior, architecture, requirements, roadmap status,
known limitations, validation results, or next steps, update the applicable file(s) in
`docs/` in the same change. Keep these notes factual and concise; do not treat a plan as
implemented work.
